# Pech — Developer Setup Guide

## 🗂️ Project Structure

```
pech/
├── api/            # FastAPI backend
├── noukpikplon/    # React frontend (Vite + TypeScript)
└── panel_admin/    # Admin panel (standalone, archived)
```

---

## 🚀 Quick Start

### 1. Prerequisites

Make sure you have the following installed:
- [Python 3.10+](https://python.python.org)
- [Node.js 18+](https://nodejs.org)
- [PostgreSQL 14+](https://www.postgresql.org)

---

### 2. Backend (API)

```bash
# Navigate to the api folder
cd api

# Create and activate a virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux

# Install dependencies
pip install -r requirements.txt
```

Now run the **automated setup script**:

```bash
# Windows (double-click or run in terminal)
API-setup.bat
```

This will:
1. Prompt you for your PostgreSQL username and password
2. Create the `pech` database
3. Generate the `.env` file automatically
4. Create all tables (via SQLAlchemy)
5. Load all seed data from `seed_data.json`

After setup, start the API server:

```bash
uvicorn main:app --reload
```

The API will be available at `http://localhost:8000`.  
Swagger docs: `http://localhost:8000/docs`

---

### 3. Frontend (noukpikplon)

```bash
cd noukpikplon
npm install
npm run dev
```

The app will be available at `http://localhost:5173`.

> **Note:** The frontend connects to `http://localhost:8000` by default (configured in `src/lib/api.ts`).

## ⚙️ Environment Variables (auto-generated by API-setup.bat)

| Variable | Description |
|----------|-------------|
| `DATABASE_URL` | PostgreSQL connection string |
| `SECRET_KEY` | JWT signing key (auto-generated) |
| `ALGORITHM` | JWT algorithm (HS256) |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | Token expiry in minutes |
| `MAIL_*` | SMTP mail configuration |

> The `.env` file is excluded from Git. It is generated automatically by `API-setup.bat`.

---

## 🗃️ Seed Data

The file `api/seed_data.json` contains a snapshot of the original database and is committed to the repository. The setup script loads it automatically.

To refresh the seed data (if you're the owner):

```bash
cd api
venv\Scripts\activate
python dump_db.py
```

## 📚 API Endpoints

- `POST /auth/signup` — Create an account
- `POST /auth/login` — Login
- `GET /users/me` — Get current user
- `GET /programs` — All course programs
- `GET /admin/*` — Admin endpoints (requires admin role)

Full documentation at `http://localhost:8000/docs`.
